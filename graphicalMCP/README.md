# RISW Short Course Examples - graphicalMCP

This folder contains documentation and examples for the RISW short course on the graphicalMCP R package.

## Files

### [RISW_graphicalMCP.Rmd](RISW_graphicalMCP.Rmd)
An R Markdown document demonstrating the graphicalMCP R package. This example includes:

- **Example 3**: A 4-hypothesis testing mentioned in the short course.

- **CANTOS Example**: An example based on the CANTOS trial.

### [RISW_graphicalMCP.html](RISW_graphicalMCP.html)
The rendered HTML output of the R Markdown document, providing a formatted presentation of embedded plots and results.

## Usage

To run the example:
1. Open [RISW_graphicalMCP.Rmd](RISW_graphicalMCP.Rmd) in RStudio
2. Ensure the `graphicalMCP` package is loaded
3. Knit the document to generate the HTML output
